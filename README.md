# 👥 Dashboard Ejecutivo: HR People Analytics & Talento

Aplicación web interactiva desarrollada con **Python** y **Streamlit** para el monitoreo estratégico de talento humano, análisis de retención de personal (*Employee Attrition*), clima laboral, equidad salarial y rendimiento por departamento.

---

## 🚀 Características Principales y Funciones Gerenciales
* **Filtros Estratégicos de Talento:** Filtrado dinámico por departamentos (Tecnología, Ventas, Operaciones, Finanzas) y niveles jerárquicos (Junior, Senior, Lead/Gerente).
* **Alertas Inteligentes de Retención:** Evaluación automática de la tasa de rotación y satisfacción laboral para disparar alertas operativas en tiempo real.
* **Tarjetas de KPIs Ejecutivos:** Indicadores consolidados de colaboradores activos, tasa de rotación (*Attrition*), satisfacción promedio y salario mensual medio.
* **Visualizaciones Analíticas (Plotly):** Gráficos de barras agrupadas para rotación por área y diagramas de caja (*Box Plots*) para distribución salarial en diseño *Dark Mode*.
* **Exportación de Reportes:** Botón interactivo para la descarga directa del directorio y reporte analítico de colaboradores filtrados en formato CSV.

---

## 🛠️ Tecnologías y Librerías Utilizadas
* **Python:** Lenguaje de programación principal.
* **Streamlit:** Framework para el desarrollo de aplicaciones web de datos y paneles ejecutivos.
* **Plotly:** Motor de gráficos interactivos avanzados.
* **Pandas & NumPy:** Estructuración, limpieza y agregación de métricas corporativas.
